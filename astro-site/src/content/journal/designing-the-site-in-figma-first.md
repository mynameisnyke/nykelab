I used to open the editor and start building. This time I spent two weeks in Figma first, and the code took a fraction of the time it normally does.

## Tokens before pages

Colours, spacing and type live as variables with a dark and a light mode. When the code uses the same names, a theme switch is one attribute on the root element.

The pages are then just arrangements of a few components. Most of the decisions were made before a line of CSS existed.
